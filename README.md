# Enterprise Meal Planner

I want create a design for a website for Enterprise Insurance that will help staff order the food they will eat the following day. No need for unnecessary sign-in / sign up. Users should be able to sign for all the days (i.e. Monday to Friday). All the necessary metrics should be in place for an administrator to see.
